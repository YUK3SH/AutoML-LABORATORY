About the Platform

AutoML Laboratory

A controlled execution environment for benchmarking multiple AutoML frameworks on any supervised learning CSV dataset — ensuring fair, reproducible comparisons.

What It Does

AutoML Laboratory runs four industry-leading AutoML frameworks — H2O, AutoGluon, TPOT, and FLAML — on the exact same 80/20 stratified train-test split of your dataset. Simply upload any CSV, select your target column — the platform auto-detects binary, multiclass, or regression, and the platform handles all preprocessing automatically: dropping ID-like columns, imputing missing values, encoding categoricals. Each framework tests two algorithms internally and returns its best model. Results are standardized into a common metrics format for direct comparison.

Works with any dataset — classification (churn, fraud, disease, spam) or regression (house prices, salary, sales forecasting). No configuration needed. No dataset-specific configuration needed.

Workflow

01
Upload CSV

Upload any CSV dataset — binary, multiclass, or regression. The platform auto-detects feature types and validates the data.

02
Single Split

One 80/20 stratified split is made. All frameworks train on the exact same data — no leakage, no bias.

03
Parallel Benchmarking

Each selected framework trains its 2 algorithms, picks the best, and returns standardized metrics.

04
AI Analysis

Google Gemini analyzes the results and provides expert recommendations and improvement suggestions.

05
Download & Compare

Download trained model artifacts as a ZIP. All experiments are saved to your dashboard history.
